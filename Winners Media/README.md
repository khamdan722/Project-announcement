# Winners Media — HF 2026

Pictures and videos for each winner of the Hamdan bin Rashid Al Maktoum Foundation
for Medical and Educational Sciences awards (HF 2026), sorted by award and winner.

## How to add media

1. Upload pictures and videos into **`00 - Upload here/`** (any file names are fine).
   Tip: put the winner's name or entry number in the file name or the commit message if you can.
   It helps with sorting.
2. Claude moves each file into the right winner's `photos/` or `videos/` folder,
   gives it a clear name, and updates the table below.

Note: GitHub's web upload accepts files up to 25 MB each. If a video is larger than
that, compress it or share a link to it instead (YouTube, Drive, etc.). Links can be logged here too.
